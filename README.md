# Visitor

A premium, interactive data visualization and exploration platform designed for temporal abstraction patient data.

## Features

- **Interactive Temporal Graphs**: Explore nominal and numeric patient timelines with granular zoom, pan, and offset navigation.
- **Patient Cohort & Group Management**: Create, edit, and filter groups of patients dynamically to analyze specific patient subsets.
- **Advanced Abstraction Rendering**: Visualize raw and abstracted categorical and numeric events seamlessly.
- **Robust Environment Integration**: Connects with backend data services to pull and persist group configurations and medical temporal queries.

## Getting Started

### Prerequisites

Make sure you have Node.js & npm (or Bun) installed.

### Installation

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   cd chart-stacks-pro
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Run the development server:
   ```sh
   npm run dev
   ```

## Technology Stack

- **Framework**: React with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS & shadcn/ui
- **Charting**: Recharts
- **State & Data Fetching**: TanStack Query (React Query)
